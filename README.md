# Team-TJ 小红书 AI Agent

Next.js App Router foundation for the Team-TJ content operations workflows.

## Commands

- `npm run dev` — start the local development server
- `npm run lint` — run ESLint
- `npm run format:check` — verify Prettier formatting
- `npm test` — run the single non-watch Vitest suite
- `npm run build` — create the production build

The initial foundation exposes `GET /api/health`. Runtime integrations, persistence, authentication, and workspace workflows are added in later implementation tasks.
